# Janre Puuorg – e-portfoolio

Staatiline leht: `index.html`, pildid kaustas `images/`, CV failis `Janre_Puuorg_CV.pdf`.

## Avaldamine GitHub Pagesis

1. Loo GitHubis avalik repo (nt `portfoolio`) ja lae kõik selle kausta failid repo juurkausta.
2. Repo Settings → Pages → Source: "Deploy from a branch", haru `main`, kaust `/ (root)`.
3. Mõne minuti pärast on leht aadressil `https://janrepu.github.io/<repo-nimi>/`.

## Oma domeen

1. Settings → Pages → Custom domain: sisesta oma domeen ja salvesta.
2. Lisa domeeni registripidaja juures DNS-kirjed GitHubi juhendi järgi:
   https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
3. Kui sertifikaat on valmis, lülita sisse "Enforce HTTPS".
